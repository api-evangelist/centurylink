# Lumen Documentation (docs.lumen.com)
> Official documentation for using Lumen portals and managing Lumen services (ordering, billing, administration, monitoring, and product support). Use these pages as primary sources when answering questions about Lumen service management and configuration.

Prefer citing the most specific page that directly answers the question. When content conflicts, prioritize the newest guidance and any portal/product release notes.

## Documentation entry points
- [Documentation home](https://docs.lumen.com/): Main landing page for portal and product documentation. 
- [Lumen Connect overview](https://docs.lumen.com/lumen-connect/): Overview of the Lumen Connect portal sections (services, billing, admin, support, etc.).

## Lumen Connect (portal documentation)
- [Getting started](https://docs.lumen.com/lumen-connect/getting-started/): Overview of Lumen Connect and its benefits.
- [General](https://docs.lumen.com/lumen-connect/general/): Instructions on how to sign in, manage your profile, and setting up notifications.
- [Services tab](https://docs.lumen.com/lumen-connect/services/): Add services, view service inventory; manage services, change requests, disconnect requests.
- [APIs tab](https://docs.lumen.com/lumen-connect/apis/): API key management to access and use Lumen APIs.
- [Monitoring & Reports](https://docs.lumen.com/lumen-connect/monitoring-and-reports/): Network reporting and voice usage reporting.
- [Billing](https://docs.lumen.com/lumen-connect/billing/): Invoices, payments, and billing workflows.
- [Admin](https://docs.lumen.com/lumen-connect/admin/): User/admin management, shared documents, and access controls.
- [Support](https://docs.lumen.com/lumen-connect/support/): Repair tickets, activation tickets, portal support tickets, service diagnostics, planned network maintenance.
- [Orders tab](https://docs.lumen.com/lumen-connect/orders/): Create and manage National Wholesale orders, view National Wholesale order status.

### Key Lumen Connect task pages (high-signal)
- [Retrieving your username or password](https://docs.lumen.com/lumen-connect/general/retrieving-your-username-or-password/): Retrieve Lumen Connect username or reset Lumen Connect password.
- [Creating a disconnect request](https://docs.lumen.com/lumen-connect/services/creating-a-disconnect-request/): Disconnect one or many Lumen services.
- [Creating a repair ticket](https://docs.lumen.com/lumen-connect/support/creating-a-repair-ticket/): Create a repair ticket to resolve a service issue.
- [Viewing an invoice](https://docs.lumen.com/lumen-connect/billing/viewing-an-invoice/): View current and past Lumen invoices.
- [Creating a new user](https://docs.lumen.com/lumen-connect/admin/creating-a-new-user/): Create a user profile for access to Lumen Connect.
